# Portfolio Web — Angular

A modern, single-page portfolio built with **Angular 17** (standalone components) and **SCSS**. The UI highlights experience, skills, and featured work in a clean, enterprise-ready layout.

## Features
- Standalone Angular component architecture
- Responsive layout with modern typography
- Structured data arrays for projects, experience, and skills
- SCSS tokens for consistent spacing, shadows, and color

## Project Structure
```
src/
  app/
    app.component.ts
    app.component.html
    app.component.scss
    app.config.ts
    app.routes.ts
  assets/
  index.html
  main.ts
  styles.scss
```

## Getting Started
```bash
npm install
npm start
```

## Build
```bash
npm run build
```

## Notes
The portfolio content lives inside `src/app/app.component.ts` and `src/app/app.component.html` for quick customization.
